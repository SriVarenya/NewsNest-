News Nest 

NewsNest is a web-based news aggregation system developed using HTML, CSS, and JavaScript to provide users with a
simple and centralized platform for accessing news. The system allows users to browse news articles across different
categories, search for specific news, filter articles based on categories, and save articles for later viewing. 
The project consists of two major modules: User Module and Admin Module. The User Module provides signup, login, news browsing,
searching, filtering, and saved-article features. The Admin Module allows authorized administrators to add and delete news articles,
manage available content, and view basic system information. Local Storage is used to store user, article, and saved-article data without
requiring a separate backend database. CSS Grid and Flexbox are used to create a structured and responsive user interface. Overall, NewsNest
demonstrates how basic web technologies can be combined to create a functional, interactive, and user-friendly news aggregation platform.
